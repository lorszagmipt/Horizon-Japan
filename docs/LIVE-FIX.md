# Как исправлять игру самому, на ходу

Есть три способа, от самого быстрого к самому надёжному.
**Перед любой правкой** открой GitHub Desktop: там видно, что изменилось.
Если что-то сломалось — правой кнопкой по файлу → **Discard changes** (вернуть как было).

---

## Подготовка (каждый раз)

1. Двойной клик по `start-dev.bat` — откроется игра в браузере. Окно с чёрной консолью не закрывай, пока играешь.
2. В VS Code: *Файл → Открыть папку →* `Рабочий стол\игра`.
3. Расставь окна рядом: слева VS Code, справа браузер с игрой.
4. В игре нажми **`** (клавиша Ё) — появится панель отладки.

---

## Способ 1. Крутить числа прямо в игре, без перезагрузки

Подходит, чтобы **подобрать значение**: сцепление, мощность, скорость.

1. В браузере с игрой нажми **F12** → вкладка **Console**.
2. Введи команду и нажми Enter — изменение действует **сразу**, машина едет дальше:

```js
__game.car.P.grip = 1.4      // сцепление (больше — меньше заносит)
__game.car.P.power = 16      // мощность (разгон)
__game.car.P.vmax = 90       // максимальная скорость, м/с (90 м/с = 324 км/ч)
__game.car.P.drift = 1.5     // насколько легко уходит в занос
__game.car.P.brake = 28      // тормоза (у первой машины 22)
```

3. Посмотреть все параметры текущей машины: `__game.car.P` (Enter).
4. Стрелка **↑** в консоли повторяет прошлую команду — удобно менять число по чуть-чуть.

**Важно:** это не сохраняется. После перезагрузки всё вернётся.
Когда нашёл хорошее число — впиши его в код (способ 2): `src/car/cars.js`, блок `phys` этой машины.

## Способ 2. Правка в коде с автоматической перезагрузкой

Подходит для **любых правок**: физика, дороги, тексты, цвета.

1. Найди нужное место (см. «Как найти, где править» ниже).
2. Поменяй число или строку в VS Code и нажми **Ctrl+S**.
3. Игра в браузере **сама перезагрузится** через пару секунд с новым кодом.
4. Если игра не загрузилась — в браузере F12 → Console покажет ошибку и строку. Обычно это опечатка: верни как было (Ctrl+Z, Ctrl+S).

### Как сделать, чтобы после перезагрузки сразу видеть тот же момент

Это главный приём для багов вроде «подлетаю на ровном месте».

1. Поймай баг в игре и сразу нажми **F8** — игра запомнит последние 10 секунд.
   (Или включи галочку **«автодетектор»** — он сам сохранит момент подлёта.)
2. Поставь галочку **«повтор после перезагрузки»**.
3. Теперь правишь код → Ctrl+S → игра перезагружается и **сама проигрывает этот момент заново**.
   Сразу видно, ушёл баг или нет.
4. **-** (минус) — замедление, **F2** — пауза, **.** — кадр вперёд, **F4** — облететь место камерой.
5. Галочка **«по кругу»** — повтор крутится без остановки, пока ты правишь.

Точка бага хранится в браузере и не пропадает при перезагрузке.
Кнопка **«Экспорт»** сохраняет её в файл — его можно прислать мне.

## Способ 3. Остановить игру на строке кода

Подходит, когда **непонятно, почему** так происходит.

1. В VS Code: **Ctrl+Shift+P** → набери `Debug: Open Link` → введи `http://localhost:5173`.
   Откроется отдельное окно с игрой, связанное с редактором.
2. Открой файл, кликни слева от номера строки — красная точка.
3. Правой кнопкой по точке → **Edit Breakpoint → Expression** → например `this.vy > 10`.
   Игра замрёт только в момент, когда машину подбросило.
4. Наведи мышь на любую переменную — увидишь её значение в этот момент.
   **F10** — следующая строка, **F5** — продолжить.

## Как найти, где править

- **Ctrl+Shift+F** в VS Code — поиск по всем файлам. Ищи по надписи из меню или по слову из комментария.
- Комментарии в коде на русском. Большие блоки подписаны заглавными, например `ВЫСОТА И ПРЫЖКИ`.
- Карта папок — в `README.md`, раздел «Где что лежит».

## Сохранить удачную правку (GitHub Desktop)

1. Открой GitHub Desktop — слева список изменённых файлов, справа что именно поменялось
   (красное — было, зелёное — стало).
2. Внизу слева в поле **Summary** напиши коротко, что сделал: «Сцепление у первой машины 1.2».
3. **Commit to main** — правка сохранена в истории.
4. **Push origin** (кнопка сверху) — копия улетает на GitHub (приватно, видишь только ты).

**Откатить:**
- ещё не сохранил коммитом → правой кнопкой по файлу → **Discard changes**;
- уже сохранил → вкладка **History** → правой кнопкой по коммиту → **Revert changes in commit**.

**Попробовать рискованную идею:** сверху **Current branch → New branch** (например `test-physics`).
Правь сколько хочешь. Не понравилось — переключись обратно на `main`, там всё как было.

---

## Правило, чтобы ничего не сломать

Меняй **одну вещь за раз** → проверь в игре → коммит.
Тогда любую ошибку легко найти и откатить.
