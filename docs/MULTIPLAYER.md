# Как играть с друзьями

В игре есть онлайн: один игрок создаёт **комнату**, остальные входят по **коду из 5 букв**.
Вместе можно просто кататься по миру или гоняться в заездах — с ботами и способностями.

## Как это устроено (коротко)

- Компьютеры соединяются **напрямую** (технология WebRTC). Чтобы найти друг друга, они один раз
  «знакомятся» через бесплатный сервер библиотеки **PeerJS** (0.peerjs.com). Свой сервер не нужен.
- Тот, кто создал комнату, — **хозяин** 👑. Он выбирает заезд, его компьютер ведёт ботов.
- Каждый сам считает физику своей машины и 15 раз в секунду отправляет, где она. Чужие машины
  плавно «дорисовываются» между сообщениями.
- Ракеты и бананы видны у всех. Попадание засчитывает тот, в чью машину попали.
- В комнате до 8 игроков.

## Шаг 0. Один раз: поставить библиотеку сети

В папке игры (в VS Code: *Терминал → Создать терминал*):

```
npm install
```

(`start-dev.bat` делает это сам, если библиотеки ещё нет.)

## Шаг 1. Проверить одному, без друзей

1. Запусти `start-dev.bat`.
2. В адресе браузера допиши `?netlocal` → `http://localhost:5173/?netlocal` и открой **второе окно**
   с тем же адресом. Поставь окна рядом (во вкладке на заднем плане игра засыпает).
3. В первом окне: **Играть с друзьями → Создать**. Появится код.
4. Во втором: **Играть с друзьями → введи код → Войти**.
5. Теперь в каждом окне видна машина из другого. В первом окне **Заезды** — оба поедут вместе.

`?netlocal` — «сеть» внутри одного браузера, интернет не нужен.

## Шаг 2. Друг в той же Wi‑Fi сети (дома)

1. Вместо `start-dev.bat` в терминале: `npm run dev -- --host`.
   Vite покажет строку `Network: http://192.168.x.x:5173/` — это адрес для друга.
2. Друг открывает этот адрес у себя (компьютер должен быть в той же сети).
3. Ты: **Играть с друзьями → Создать**, говоришь другу код, он входит.

Интернет всё равно нужен — для знакомства через сервер PeerJS.

## Шаг 3. Друзья где угодно (через интернет)

Друзьям нужна **та же игра по ссылке**. Пока игра не на Яндекс Играх, проще всего так:

1. В терминале: `npm run build` — появится папка `dist` (готовая игра).
2. Открой **https://app.netlify.com/drop** и перетащи туда папку `dist`.
   Через несколько секунд будет ссылка вида `https://какое-то-имя.netlify.app`.
   (Без регистрации ссылка живёт час; зарегистрируйся там же — будет постоянной.)
3. Отправь ссылку друзьям. Все открывают её, ты создаёшь комнату, друзья входят по коду.

Когда игра появится на Яндекс Играх — играйте прямо там, так же по коду комнаты.

## Что делать, если не подключается

| Что видно | Что делать |
|---|---|
| «Комната ABCDE не найдена» | Проверь код. Хозяин должен держать игру открытой. |
| «Нет ответа от комнаты» | Обычно мешает сеть (строгий роутер, мобильный интернет, VPN). Попробуйте другую сеть или выключите VPN. |
| Машина друга дёргается | Слабый интернет у кого-то из вас. Сглаживание — `NET_DELAY` в `src/net/net.js` (больше — плавнее, но с запаздыванием). |
| Хозяин вышел — всех выкинуло | Так задумано: комната живёт, пока открыта у хозяина. |

## Где что в коде

| Хочу поменять | Где |
|---|---|
| Как часто отправляется положение, сглаживание | `src/net/net.js` → `NET_RATE`, `NET_DELAY` |
| Экран «Играть с друзьями» | `src/ui/ui.js` → `openOnline` |
| Боты: сила, «резинка», решётка | `src/race/bots.js` → `BOT_LEVELS`, `BOT_TUNE` |
| Способности: скорость ракеты, шансы в коробках, шкала | `src/race/items.js` → `ITEM_TUNE` |
