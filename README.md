# Painted Roads — проект игры

Браузерная гонка по Японии: процедурный мир, своя физика машины, рендер на WebGL2.
Код восстановлен из собранного файла `reference/original-game.html` и разложен по модулям.
Поведение проверено автопилотом: все 6 заездов проходятся с точно такими же результатами, как в оригинале.

## Установить один раз

1. **Node.js** — скачай версию **LTS** с https://nodejs.org и установи (все галочки по умолчанию).
2. **VS Code** — уже есть. Русский интерфейс: слева «Extensions» (Ctrl+Shift+X) → найди *Russian Language Pack* → Install.
3. **GitHub Desktop** — уже есть. *File → Add local repository →* выбери эту папку → *create a repository*.

## Запустить игру

**Самый простой способ:** двойной клик по `start-dev.bat`. Первый раз он сам скачает Vite (около минуты),
потом откроет игру в браузере.

**Из VS Code:** *Файл → Открыть папку* → эта папка. Дальше *Терминал → Создать терминал* и команды:

```
npm install      (только первый раз)
npm run dev
```

В терминале появится ссылка `http://localhost:5173/` — открой её.
Пока игра запущена, любое сохранение файла в `src/` сразу перезагружает её в браузере.

## Отладка: остановить игру на нужной строке

1. Запусти игру (`npm run dev` в терминале VS Code или `start-dev.bat`).
2. В VS Code нажми **Ctrl+Shift+P**, набери **Debug: Open Link** и введи `http://localhost:5173`.
   Откроется отдельное окно браузера, подключённое к редактору.
3. Открой нужный файл, например `src/car/physics.js`, и кликни слева от номера строки — появится красная точка.
4. Когда игра дойдёт до этой строки, она замрёт, а в VS Code будут видны все переменные в этот момент.
   Наведи мышь на переменную — увидишь её значение.
5. Правой кнопкой по красной точке → «Изменить точку останова» → «Условное выражение», например `this.vy > 10`.
   Тогда игра остановится только в момент подлёта.
6. **F5** — продолжить, **F10** — следующая строка, **Shift+F5** — остановить отладку.

Ошибки и сообщения игры видны в консоли браузера (**F12** → *Console*) с точным файлом и строкой.

## Режим отладки внутри игры

Включается сам при запуске через `npm run dev` (в архив для Яндекса не попадает). Код — `src/debug/debug.js`.

| Клавиша | Что делает |
|---|---|
| `` ` `` (Ё) | показать / скрыть панель отладки |
| **F2** | пауза физики (стоп-кадр); **.** (точка) — один кадр вперёд |
| **F4** | свободная камера: W A S D — лететь, Пробел / Z — вверх / вниз, Shift — быстрее, колесо — скорость полёта, зажать мышь — смотреть |
| клик по земле | на паузе — закрепить точку и увидеть всё о ней (высоты, дорога, покрытие) |
| **T** | в свободной камере — перенести машину в точку под прицелом |
| **-** | замедление времени ×1 → ×0.25 → ×0.1 |
| **F8** | сохранить «точку бага» — последние 10 секунд езды |
| **F9** | повторить точку бага |

**Панель** показывает скорость, положение, вертикальную скорость `vy`, на земле ли машина, покрытие, дорогу.
**График** — последние 8 секунд: синяя линия — `vy` машины, оранжевая — скорость подъёма земли под ней,
розовый фон — машина в воздухе, красная черта — сработал автодетектор.

**Слои поверх картинки:** жёлтые/оранжевые/красные — препятствия (стволы, отбойники, стены),
белые линии — край асфальта, голубой пунктир — граница, где для физики кончается дорога,
красные и жёлтые столбики — «ступеньки» высоты между дорогой и землёй (подпись — высота в метрах),
зелёные круги — как машина видит себя при столкновениях.

**Точка бага.** Игра всё время помнит последние 12 секунд: состояние машины и нажатые клавиши в каждом кадре.
F8 сохраняет их, F9 ставит машину туда, где она была, и проигрывает те же нажатия — физика повторяет всё
точь-в-точь. Ползунок «Начать за … с» выбирает, с какого момента начать повтор. «Экспорт» сохраняет точку
в файл `.json` — его можно прислать мне, и я воспроизведу баг у себя. «Автодетектор» сам сохраняет точку,
когда машина отрывается от земли со скоростью вверх больше 5 м/с.

### Как чинить баг вроде «подлетаю вверх на ровном месте»

1. Подлетел — нажми **F8** (или автодетектор сохранит сам).
2. Поставь галочку **«повтор после перезагрузки»** и нажми **F9**. Включи замедление (**-**) и смотри на график
   и панель: в какой момент `vy` прыгнула и что было под машиной (покрытие, дорога, высота).
3. **F2** — пауза в нужный момент, **F4** — облети место, включи слои «края дорог» и «ступеньки», кликни по земле.
4. Открой код (`src/car/physics.js`, блок «ВЫСОТА И ПРЫЖКИ», или `src/world/world.js` → `groundAt`),
   поправь и сохрани файл. Игра перезагрузится и **сама сразу повторит** точку бага — видно, ушёл ли он.
5. Чтобы остановиться прямо на строке кода в момент бага — точка останова в VS Code
   (раздел «Отладка» выше) с условием, например `this.vy > 10`.

## Собрать архив для Яндекс Игр

```
npm run zip
```

Появится `yandex-game.zip`: в корне архива `index.html`, а рядом папка `assets` с игрой.
Именно его загружают в консоль Яндекс Игр.

## Частые правки

- **Мощность / скорость / сцепление машины** → `src/car/cars.js`, блок `phys` нужной машины
  (`power` — тяга, `vmax` — максимальная скорость в м/с, `grip` — сцепление, `drift` — лёгкость заноса, `brake` — тормоза).
- **Поведение всех машин сразу** → `src/car/physics.js`, метод `step` (блоки подписаны комментариями).
- **Форма дороги** → `src/world/mapData.js`, массив `ROADS`, точки `pts` (метры, X — восток, Z — север).
- **Время на медали** → `src/race/events.js`, поле `vref` у заезда.
- **Тексты меню** → `src/ui/ui.js` (поиск по тексту: *Правка → Найти в файлах*, Ctrl+Shift+F).

## Как искать нужное место в коде

- **Ctrl+Shift+F** — поиск текста по всем файлам (например, по надписи из меню).
- **Ctrl+P** — быстро открыть файл по имени.
- **F12** на названии функции — перейти туда, где она написана.
- **Shift+F12** — найти все места, где она используется.
